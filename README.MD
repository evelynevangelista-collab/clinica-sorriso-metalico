O cliente do projeto, é o Dr. Roberto, o qual solicitou um sistema de gestão clínica de elite. Com base no contrato e seguindo as cláusulas e expecificações estritamente definidas. O sistema deve fazer o cadastro de pacientes e agendamento das consultas, deve ter uma agenda inflexível para clientes comums em horários nobres (noites e sabados). O próprio cliente fará a classificação manual de clientes VIPs. O sistema deverá registrar o histórico do prontuário do paciente com as anotações técnicas do procendimento e ter uma interface gráfica rápida e elegante.
